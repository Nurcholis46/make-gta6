Sunset Bay — a 3D open-world crime game that runs in a desktop browser from static files. Drive and steal cars across a sun-soaked coastal city, outrun the police at up to 5 wanted stars, and run five story jobs for Mama Rosa. On foot and behind the wheel, with traffic, pedestrians, combat, a HUD and minimap, saves, and original WebAudio music and effects. All original — no Rockstar assets.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

No build step, no network request while playing. Keyboard + mouse: WASD to move and drive, mouse to look, E to steal or exit a car, click to shoot, Shift to sprint, Space to handbrake, P to pause, M to mute.
